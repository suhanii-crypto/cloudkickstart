The essentials

Three services to know

🖥️ Amazon EC2

Provides virtual servers in the cloud so applications can run without owning physical servers.

🗂️ Amazon S3

Object storage for files, images, documents and backups, with access controls to help protect data.

🚀 AWS Amplify

Helps developers build and deploy web applications, including hosting supported frontend projects.
